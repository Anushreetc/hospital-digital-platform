# ElevenLabs voice agent — setup

The voice agent books OPD appointments in Kannada or English and sends every
conversation (transcript + booking) to **Reception → AI Receptionist Desk**.

```
Patient (website now, phone line later)
   │  WebRTC
   ▼
ElevenLabs agent ──server tools──► Supabase Edge Function  voice-tools
   │                                   └─► book_appointment / get_available_slots (same as the website form)
   │  post-call webhook
   ▼
Supabase Edge Function  voice-call-log ──► public.voice_calls ──Realtime──► Reception portal
```

Both Edge Functions are deployed to the **We Care Hospital** Supabase project
(`cienqtqfgqrdasdpezxe`). Secrets are kept in Supabase **Vault** (Dashboard →
Project Settings → Vault), never in the frontend.

| Vault secret | Purpose |
|---|---|
| `voice_tools_secret` | Generated by migration `20261030000000_voice_agent.sql`. ElevenLabs sends it as header `x-voice-secret` on every tool call. |
| `voice_webhook_secret` | Issued by ElevenLabs when the post-call webhook is created (step 5). Add it with `select vault.create_secret('<secret>', 'voice_webhook_secret');` |

The steps below describe how the agent was built, for re-creating it in another workspace.

## 1. Create the agent
ElevenLabs → Agents → Create agent → Blank.

- **Name:** We Care Hospital Receptionist
- **Language:** English as default, add **Kannada** as an additional language, enable language detection.
- **Voice / TTS model:** a model that lists Kannada (Eleven v3 or newer). Pick a warm female Indian voice and test Kannada pronunciation.
- **LLM:** a fast tool-calling model (e.g. Gemini Flash / GPT-4o-mini / Claude Haiku class). Temperature low (≈0.3).
- **First message:**
  `ನಮಸ್ಕಾರ! ವೀ ಕೇರ್ ಆಸ್ಪತ್ರೆಗೆ ಸುಸ್ವಾಗತ. Namaskara, welcome to We Care Hospital. This is the automated assistant. How can I help you today?`
- **Dynamic variable:** `preferred_language` (default `Kannada`) — the website sends `Kannada` or `English`.

## 2. System prompt
```
You are the automated receptionist of We Care Multispeciality Hospital and ICU, Doddaballapura, Karnataka.
The caller prefers {{preferred_language}}. Reply in the language the caller is using; Kannada, English and a natural mix are all fine.
Today's date comes from the hospital_info tool (field "today", Asia/Kolkata). Use it to resolve "today", "tomorrow", "next Monday".

You can:
- Book OPD appointments.
- Answer questions about the hospital (address, phone numbers, visiting hours, insurance) using hospital_info only.

Booking steps:
1. Find the doctor with search_doctors (by name, specialty or the caller's described problem area). Never invent doctors.
2. Ask the preferred date and call check_slots. Offer at most three times from the result. If there are none, offer next_available.
3. Collect the patient's full name, 10-digit mobile number and a short reason for the visit.
4. Read back doctor, date, time, patient name and the mobile number digit by digit, and ask the caller to confirm.
5. Only after a clear "yes", call book_appointment with conversation_id = {{system__conversation_id}}.
6. Read the reference code and token number slowly. Say that reception will call to confirm the appointment.
If book_appointment returns ok:false, explain the error simply and offer another slot.

Rules:
- Keep each reply to one or two short sentences; this is a spoken conversation.
- Never give medical advice, diagnoses, medicine names or doses. Say the doctor will advise during the consultation.
- Emergencies (chest pain, breathing difficulty, heavy bleeding, unconsciousness, stroke signs, severe injury): stop booking and tell the caller to call 108 or the hospital emergency line +91 88677 55541 immediately, or come to casualty.
- Do not discuss room prices or fees; say reception will help on +91 88677 55541.
- If the caller asks for a person, give the reception number +91 88677 55541.
```

## 3. Server tools (Agent → Tools → Add tool → Webhook)
For every tool: method **POST**, header `x-voice-secret: <Vault voice_tools_secret>`,
base URL `https://cienqtqfgqrdasdpezxe.supabase.co/functions/v1/voice-tools/`.

| Tool name | URL suffix | Body parameters (all strings) | Description for the LLM |
|---|---|---|---|
| `hospital_info` | `hospital_info` | — | Hospital address, phone numbers, visiting hours, insurance info and today's date. |
| `search_doctors` | `search_doctors` | `query` (optional): doctor name, specialty or body area | Lists active doctors with their doctor_id. |
| `check_slots` | `check_slots` | `doctor_id` (required), `date` YYYY-MM-DD (required) | Open OPD times for that doctor and date; suggests next available days if none. |
| `book_appointment` | `book_appointment` | `conversation_id` (dynamic variable `system__conversation_id`), `doctor_id`, `date` YYYY-MM-DD, `slot_time` (e.g. "10:30 AM" or "10:30:00"), `patient_name`, `patient_phone` (10 digits), `reason`, `language` ("KN" or "EN") | Books the appointment. Call only after the caller confirmed all details. |

Tool errors come back as `{ "ok": false, "error": "..." }` so the agent can read them out.

## 4. Analysis → Data collection
Add these items so Reception sees caller details even when no booking was made:

| Identifier | Type | Description |
|---|---|---|
| `patient_name` | string | Caller's or patient's full name, if given. |
| `patient_phone` | string | 10-digit mobile number, if given. |
| `language` | string | `KN` if the caller mainly spoke Kannada, otherwise `EN`. |
| `intent` | string | One of `APPOINTMENT_BOOKING`, `EMERGENCY_QUERY`, `DOCTOR_ENQUIRY`, `GENERAL_OPD`. |

## 5. Post-call webhook
Settings (workspace) → Webhooks → create:
`https://cienqtqfgqrdasdpezxe.supabase.co/functions/v1/voice-call-log`, event **post-call transcription**,
HMAC authentication. Copy the secret ElevenLabs shows into Vault as `voice_webhook_secret`, then enable the
webhook for this agent.

## 6. Website
Agent → Security: make the agent public for the web widget and add the hospital's site
domains (and `localhost:5173` for testing) to the allowlist. Put the agent ID in the
frontend build environment:

```
VITE_ELEVENLABS_AGENT_ID=<agent id>
```

Rebuild and redeploy. The **Voice Call** tab in the website assistant then connects to the agent.

## 7. Later: phone number
When the hospital's +91 number is approved (Exotel / Plivo / another SIP provider), import it under
Agents → Phone numbers via SIP trunk and assign this agent. No code changes are needed; the same tools
and webhook apply. SMS/WhatsApp confirmation can be added to `voice-call-log` once DLT templates are approved.

## Test checklist
- Book in Kannada and in English from the website; check Reception → Appointments (source Voice AI, status New)
  and Reception → AI Receptionist Desk (transcript, linked booking) appear without reloading.
- Ask for a Sunday or a fully booked day; the agent should offer `next_available` dates.
- Give an invalid phone number; the agent should ask again.
- Mention chest pain; the agent should give 108 / emergency number and not book.
